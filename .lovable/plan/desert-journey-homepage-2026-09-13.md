# Desert Journey Homepage

## Goal
Recreate the supplied desert travel homepage as a polished, responsive single-page experience, using the screenshots as visual references rather than embedded page images.

## Build
- Create a full-screen sunset desert opening section with navigation, luxury travel branding, safari call-to-actions, and service highlights.
- Add the split story section with layered desert photography, editorial typography, supporting copy, and trust statistics.
- Build three detailed desert package cards, followed by a scenic customer review section and three exclusive attraction cards.
- Add a visually matching footer because the referenced sixth image was not included.
- Make navigation, calls-to-action, package controls, and review controls usable.
- Adapt every section for phone, tablet, and desktop layouts without clipped text or overlapping content.

## Visual system
- Match the references’ deep green, warm ivory, amber-gold, and desert-orange palette.
- Use an elegant high-contrast serif for major headings, clean sans-serif for body copy, and a handwritten accent only where shown.
- Generate a cohesive set of desert safari, camp, Dubai, Abu Dhabi, and Hatta imagery rather than using the screenshots themselves.
- Preserve the editorial spacing, compact card corners, fine divider lines, and restrained motion.

## Technical details
- Define the palette, typography, shadows, and reusable effects as semantic tokens in the global design system.
- Implement the page in the existing TanStack Start home route and add complete page metadata.
- Use locally stored generated image assets and accessible image descriptions.
- Verify the finished page in desktop and mobile browser sizes.
